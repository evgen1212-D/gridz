Возможности

Всё для работы с XML-документами

Более 40 видов схем ФГИС ЛК: лесная декларация, отчёт об использовании, таксационное описание, договоры аренды.

Визуальная маркировка

Зелёный — обязательный блок, жёлтый — опциональный. Кнопки «Добавить / Удалить» для множественных блоков.

Списки «значение | код»

Например: «Валаамское, Сортавальское | 10:16:1». Автодополнение по значению или коду.

Умный импорт XML

Совпадающие поля заполняются даже если структура исходного XML отличается.

Панель ошибок

Клик по ошибке — переход к нужному полю. XML формируется всегда, можно дозагрузить позже.

Блочная работа

Сохраняйте блоки в файл и вставляйте в другие формы. Буфер обмена между вкладками.

Автозаполнение файлов

Имя файла, URI и MD5-хеш — из указанной папки одним кликом.

Импорт координат

KML, GeoJSON, GPX → поля «Долгота», «Широта» в формате XSD.

Печать и Excel

Печать в PDF и копия таблицы в буфер для вставки в Excel.

Валидация по XSD

Клик по ошибке — переход к полю формы.

Не заполнено: Идентификатор поставщика данных
Не заполнено: Номер таксационного описания
Значение не из списка субъектов РФ
Не заполнено: Фамилия

Загрузка XML

Даже если структура исходного XML другая — все совпадающие поля заполнятся.
