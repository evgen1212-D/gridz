Документация

Как установить приложение и работать с программой «Лесосека» — по шагам с примерами интерфейса.

Установка программы

Приложение устанавливается как PWA — без магазинов приложений.

Настольные браузеры. В адресной строке выберите «Установить приложение».

Мобильные браузеры. Меню → «Добавить на главный экран» / «Установить» / «Добавить на телефон».

iPhone. Кнопка «Отправить» → «На экран Домой».

Разрешения. Если ярлык не создаётся — дайте браузеру право размещать ярлыки (обычно в «Дополнительных разрешениях»).

Работа с программой

Пошаговые скриншоты по каждому разделу таксации.

Общие сведения

Целевое назначение, № квартала, выдела, лесосеки, площадь.

Метод таксации

Перечёт по 2-см ступеням, учёт семенников и подроста, модельные деревья.

Перечёт по 2-см ступеням

Объём промежуточных ступеней — линейной интерполяцией.

Быстрый перечёт (тап/клик)

«+1 / −1» на смартфоне и ПК, со звуковым сигналом.

Таксация лесосеки

Порода, разряд высот, таблицы для каждой колонки.

Ленточный перечёт

Количество лент, длина и ширина каждой.

Круговые площадки

Постоянный радиус, автоматический расчёт площади перечёта.

Реласкопические площадки

Полнотометр, средние D и H, половинчатые площадки.

Угол наклона площадки

Автоматическое дублирование по колонкам.

Показатели для ТОЛ

Средние H, D, класс товарности, бонитет, состав.

Учёт семенников

Количество семенных групп и их площадь.

Семенники — ведомость

Порода, разряд высот, количество по диаметрам.

Учёт подроста

Количество площадок и их площадь.

Подрост — ведомость

Пересчёт на крупный и на 1 га автоматически.

Модельные деревья

Ступени толщины и измеренные высоты, разряд — автоматически.

Абрис

Румбы, калибровка отрезка, корректировка невязки.

Коэффициенты

К ставкам — от запаса, индексации, склонов и сохранения подроста.

Итоговые результаты

Объём и сумма по породам и в целом, дровяная древесина.
